Memory model

The model that writes Cairn's memory. Any capable general-purpose model works, including your roleplay one; a cheaper one saves money. Nothing happens until one is chosen.
This is the profile your chat uses. That works if it's a general-purpose model. Roleplay finetunes tend to drift when writing summaries, so pick a separate profile if yours is one.
